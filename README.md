# MSHK.FILM — сайт-портфолио

Одностраничный сайт Михаила Мушкачева (MSHK.FILM): кинематографист из Омска.
Постановочные ролики и реклама — история, свет, съёмка и монтаж.
Собран на Vite + React + TypeScript + Tailwind CSS v4, на выходе — один статический
`index.html` со встроенными стилями, скриптами и шрифтами.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # предпросмотр собранной версии
```

Собранный `dist/` — обычная статика: его можно положить на любой хостинг,
в корень домена или в подпапку. Ссылки на медиа относительные (`assets/...`),
поэтому сайт работает и на GitHub Pages в подпапке `/mshkfilm/`.

**Живая версия:** https://conradipui-glitch.github.io/mshkfilm/
Деплой — GitHub Actions (`.github/workflows/deploy.yml`), каждый пуш в `main`
пересобирает и публикует сайт. Вместе с сайтом публикуются и ролики (~141 МБ).

### Заглушка на случай пропажи видео

`WorkPlayer` и монитор слушают `onerror` у `<video>`. Если файл недоступен
(удалили, хостинг лёг, ссылка битая), вместо плеера автоматически показывается
кадр с подписью «Видео недоступно — оригинал живёт в канале» и ссылкой на пост,
а монитор возвращается к обложке. Проверено подменой src на несуществующий файл.

## Контент

`src/data/content.ts` — единственное место, где меняются тексты.

- **Работы** — 8 публикаций, все играют на странице. Даты, роли и
  хронометраж сверены с постами. Порядок — от постановочного кино к атмосфере
  и бэкстейджу. Категории: постановка (3), реклама (1), атмосфера (3),
  бэкстейдж (1).
- **Плеер** — клик по строке или по кнопке монитора открывает работу поверх
  страницы: видео с звуком и нативными контролами, метаданные, ссылка на
  оригинал. Esc — закрыть, ← → — соседние работы.
- **Услуги, процесс, FAQ** — описание работы, без обещаний и цифр, которых нет.
- **Бриф** — собирает сообщение и открывает Telegram с готовым текстом.
  Никакой серверной части и хранения данных нет.

## Проверено

- консоль и сеть: 0 ошибок, 0 неудавшихся запросов (headless Chrome, CDP);
- горизонтального переполнения нет на 1440, 390 и 320 px;
- контраст текста: все содержательные элементы ≥ 4,5:1 (крупные — ≥ 3:1),
  кроме декоративных (бегущая строка, номера дублей);
- интерактив: аккордеон, фильтры (перенос строк, без горизонтального скролла),
  синхронизация списка и монитора, бриф, мобильное меню, `prefers-reduced-motion`;
- плеер: открытие карточки и видео, автозапуск со звуком, Esc, стрелки,
  блокировка прокрутки и возврат фокуса; на 390 px — без переполнения.

## Что нужно для публикации

1. Домен (например, `mshk.film`) и хостинг статики: Cloudflare Pages, Netlify,
   GitHub Pages или обычный сервер.
2. Абсолютный URL для `og:image` в `index.html` (сейчас относительный путь:
   соцсети не умеют его разрешать, нужен `https://домен/assets/img/og.jpg`).
3. При желании — версии выше 720p (исходники в экспорте есть) или перевод
   видео на R2.
4. Согласие Михаила на публикацию и проверка текстов от первого лица.
